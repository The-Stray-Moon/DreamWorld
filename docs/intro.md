# 梦世界

这是一个与睡觉和做梦有关的探索向模组。

本模组没有添加传统的新维度，而是加入了所有维度的原始镜像——梦世界，这个世界兼具美观与实用，你可以制作全套梦境合金装备来进行跨越空间的操作，也可以和心上人体验一次在梦中的天空划船。

## 入梦

现在玩家可以席地而睡了，不需要床，但只有在床上睡觉才能设置重生点。

玩家睡醒，或者有生物从梦世界返回现实，身边都会飘着一个粉色的小团，称作梦境橡皮泥，交互即可采集。

梦境橡皮泥可以烧制成梦境结晶，梦境结晶在砂轮磨成梦境粉末，梦境粉末酿造成梦境奶茶。

![img](https://resource-api.xyeidc.com//client/members/pics/d6d7b755)

喝了梦境奶茶后会获得梦游效果，梦游效果下，玩家可以无条件睡觉，睡着后即可进入梦世界的**对应坐标**。

梦世界不是单独的维度，而是当前维度的异化版，它保留着世界受玩家改动之前的原始地形，这里没有黑夜，连洞穴里都很明亮，天空始终飘着花瓣，方块、天空、水，都被染成童话一般的颜色。

梦世界的方块无法被破坏，无法被交互，也不会同步现实的变化，只有梦境合金系列装备才能破坏梦世界的方块。

梦世界的天空与地面的色彩会随机交换，地面的着色会有浮动，不同类型方块的着色也会有浮动，可以在配置文件中调整。

入梦的生物才会来到梦世界，这里的原住民只有果冻兔，一种蓝白色的蠢萌兔子，未来它还会出现在即将到来的汐浮维度，但现在先混个脸熟。

果冻兔周围会时不时产出梦境橡皮泥，同时，在果冻兔身边睡觉会立即入睡，你还可以手持梦境奶茶来吸引它们跟着你走。

果冻兔可以出现在有玩家活动的任何地方，且无法被攻击，但只会出现在梦世界。

萌趣的世界更受大众喜爱！

在梦世界，玩家可以无条件睡觉，入梦后会返回现实中的**对应坐标**。

## 梦行舟

在梦世界，船是重要的交通工具：
- 可以在地上划船，就像在冰面一样，但可操控性大幅增加。还可以在岩浆里划船。
- 船可以跳跃，还可以爬坡，绝不是马那样的机械爬坡，而是高性能的预测式爬坡。
- 船有亮闪闪的尾焰！

![img](https://resource-api.xyeidc.com//client/members/pics/b0315ff2)

通过梦中划船来跑图是不错的选择，经济实惠，哪里都能去。

如果需要速度更快、更稳定的移动方式，就需要用到梦境甬道。

梦境粉末和画可以合成梦境涂鸦，梦境涂鸦可以放置在现实或梦世界，会在另一侧同步。

在梦世界，任意两个梦境涂鸦之间会连成梦境甬道，甬道数量可以在配置文件中设置。

乘坐船时交互即可吸附到甬道上，也可以随时点击其他甬道来切换，跳跃脱离，疾跑翻转方向。

在甬道上划船时，船拥有在蓝冰上的速度，并且起步加速大幅缩短，此时船的方向被锁定，只能往甬道的方向前进，但无视任何地形阻碍。

这就是最最新潮的交通方式，又快又便捷。

此外，在梦境涂鸦附近睡觉时，入梦时间会得到缩减，可以在配置文件中修改。

## 梦境合金

梦境结晶与铁锭、萤石可以合成梦境合金，用于制作梦境合金装备。

梦境合金剑能造成9点伤害，梦境合金铲有比钻石高一级的挖掘速度，能挖掘一切方块，而梦境合金魔杖可以蓄力引起定点爆炸。

只有梦境合金装备才能在梦世界中攻击生物或破坏方块。

这三者都会引发名为梦境侵入的现象，被杀死的生物或被破坏的方块，会从一侧转移到另一侧，如在现实中实用梦境合金剑杀死一个僵尸，那么僵尸就会去往梦世界。

来到梦世界的其他生物，会进入睡觉状态，原地躺下，不再活动，也不会受到任何伤害，这可以是捕捉生物的一种手段，让它长眠。

被转移到梦世界的其他方块，会以原色渲染。

![img](https://resource-api.xyeidc.com//client/members/pics/d2170834)

上述说的转移行为也是对应坐标的，而梦境合金矛能改变转移的方式。

梦境合金矛的行为类似三叉戟，但无法造成伤害，投掷出去后会形成梦境锚点，可以插在生物身上，投掷在哪一侧，锚点就在哪一侧。

每一个玩家同时只能在每一侧存在一个锚点，锚点对梦境侵入现象以及玩家出入梦世界的行为生效。

简单来说，**在某一侧的锚点会把玩家在这一侧的位置固定在锚点位置**，而转移行为，是以玩家坐标为参考系去平移。

例子一：你想养点宠物，于在家的梦世界对应位置插一根梦境合金矛，然后去旅行，旅途中用梦境合金剑杀死想要捕捉的生物，这些生物在进入到梦世界后，都会出现在锚点的位置也就是家的位置，最后你再挨个遣返到现实安顿好。

例子二：你想在家门口建一座劫掠塔但不想自己动手，于是在家门口插了一根梦境合金矛，然后找了一座野生劫掠塔，利用梦境合金魔杖三下五除二就炸完了，这座劫掠塔被转移到了梦世界，接着你去梦世界，在边上再插一根梦境合金矛，再炸一遍，劫掠塔就出现在了家门口，你这时候离开梦世界，正好就回到了家里。

例子三：你在闪电飞龙身上插一根梦境合金矛，不管它飞了多远，只要你进入梦世界再出来，就能出现在它的位置。其实你直接投出去也能飞挺远的。

总之，利用梦境合金系列装备，就能随时来一场跨越空间的奔赴。
